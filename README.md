## Md. Saihan Alam

CSE @ Dhaka International University · Embedded systems · Applied ML

I build things that run close to the hardware: microcontrollers, sensors, and
small neural networks that have to work without a cloud behind them. Most of
my work sits where embedded C++ meets machine learning.

### Selected work

**[Fall Detection & Emergency Alert](https://github.com/Saihan-DIU/Fall-Detection-and-Emergency-Alert)** · *in progress*  
Low-cost wearable that detects falls on-device with TinyML and sends an SMS with
GPS coordinates over GSM. It needs no internet connection and no smartphone.  
`ESP32` `TensorFlow Lite Micro` `C++` `MPU6050` `GSM` `GPS`

**[Student Management System](https://github.com/Saihan-DIU/student-management-system)** · *complete*  
Web app for student records, grades and course enrollment.  
`JavaScript` `HTML` `CSS`

**Gesture-controlled robot** · *in progress*  
Computer-vision gesture recognition driving a mobile robot platform.
